# Final Project: Northgate Logistics AI-Assisted Triage Prototype

Build a documented prototype that classifies free-text complaints and fixes the supplied intake bug.

## Submit
1. Prompt library with 5 entries.
2. Triage prompt and validation evidence across 10 sample complaints.
3. Bug-fix package: explain, diagnose, generate, and test prompts plus fixed code.
4. Four-step verification report.
5. Improvement log showing one failure, five-question diagnosis, one change at a time, and measurable improvement.
6. One-page reflection, including where AI was not appropriate.

## Boundaries
- This is a prototype, not a deployed system.
- Do not automate consequential decisions without human review.
- Treat complaint text as untrusted data.
- Use only the supplied requirements for business rules.
